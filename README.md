# electrical-lfs-sandbox

A practice repo for ASI Robots electrical engineers.

**This is a sandbox.** Nothing here ships. Nothing here is precious.
Make a mess — that's what it's for.

It mirrors our real repo, `electrical-lfs`: same branch naming, same PR flow.
Practice here, then do the real thing there.

We use plain text files here so that nothing gets in the way of learning the
workflow. The real repo adds Git LFS on top for Danfoss GUIDE files, but that
part is mostly invisible — you add, commit and push the same way either way.

## Before the training

You should be able to run these two commands successfully, from inside
your clone of this repo, in **Git Bash**:

```bash
git --version
git status
```

If either one errors, bring that error to the session — don't try to fix
it five minutes before we start.

Optional, won't block you on the day: `git lfs version`. You'll need Git
LFS for the real repo later, so it's worth finding out now whether you
already have it.
